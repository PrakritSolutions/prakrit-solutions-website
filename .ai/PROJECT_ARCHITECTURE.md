## Overview
Single Next.js 16 App Router application deployed on Vercel. No database, no auth, no queue. Content is code (TypeScript modules). Only server logic: `POST /api/contact`. Verified by reading source, 2026-09-26.

```
Browser
  |  pages (static/RSC), client comps: contact-form, cookie banner, GA, attribution
  v
src/proxy.ts  --(COMING_SOON=true)--> rewrite everything to /coming-soon
  |
  v
App Router pages (src/app/*) <-- content in src/lib/content/*, config in src/lib/site-config.ts
  |
  +-- POST /api/contact  (src/app/api/contact/route.ts)
        |-- honeypot ("website" field) -> fake ok
        |-- in-memory rate limit 5 / hour / IP (per instance)
        |-- validate name+email+project; describeSource() sanitises UTM/ref
        |-- logEnquiryToSheet() ---> Apps Script web app ---> Google Sheet (optional, never throws)
        |-- Resend API: notification -> hello@ (reply_to visitor); 502 on failure
        |-- Resend API: confirmation -> visitor (failure only logged)
```

## Modules
- `src/app/layout.tsx`: fonts (Geist, Geist Mono), metadata, Organization JSON-LD, skip link, draft banner, Navbar/Footer, Vercel Analytics + Speed Insights, GA4, cookie banner, attribution capture. Coming-soon mode renders none of the chrome.
- `src/lib/site-config.ts`: `siteConfig` (name, email addresses, WhatsApp, hours, Calendly, location), `socialLinks` (empty hrefs are not rendered), `isDraftEnvironment`, `isComingSoon`, nav definitions.
- `src/lib/legal-config.ts`: operator, effective date (1 October 2026), retention 24 mo, analytics retention 14 mo, liability cap INR 5,000. Rendered into `/privacy` and `/terms` (TSX, not the markdown in `docs/legal`).
- `src/lib/consent.ts` + `components/analytics/*`: consent stored in `localStorage` key `prakrit-analytics-consent`; GA loads only after "granted"; consent required only when `NEXT_PUBLIC_GA_MEASUREMENT_ID` is set.
- `components/analytics/attribution.tsx`: stores UTM params/referrer in `sessionStorage` key `prakrit-attribution`; form sends it; server reduces to "source / medium / campaign", "referral: host" or "direct".
- `src/lib/contact-email.ts`: `ContactPayload`, `escapeHtml`, `buildConfirmationEmail` (HTML+text).
- `src/lib/enquiry-log.ts`: POST JSON (as `text/plain`) with secret to Apps Script; 8 s timeout.
- `integrations/google-sheets/Code.gs`: `setup()` (destructive, clears sheet), `doPost`, `safeCell` (formula-injection guard), `listRows`, `upgrade()` (adds Source and Fit columns), Status dropdown, Reply-due colouring, IST timezone. Auth: `WEBHOOK_SECRET` script property.
- `src/lib/content/*`: services, solutions, what-we-build, process, why-us, faq, case-studies. Case studies have `placeholder` flag (sitemap excludes placeholders) and optional `status`.
- SEO: `sitemap.ts`, `robots.ts` (disallow all on draft; `/api/` disallowed in prod), `opengraph-image.tsx`, `structured-data.ts`, icons.
