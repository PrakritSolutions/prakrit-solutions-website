## Architecture summary
Single Next.js App Router app, mostly static content-driven pages (content in `src/lib/content/*`), one API route `POST /api/contact` (honeypot, in-memory rate limit, Resend notification + visitor confirmation email, optional Google Sheet log). Consent-gated GA4. `src/proxy.ts` rewrites all pages to `/coming-soon` when `COMING_SOON=true`. Draft mode (`NEXT_PUBLIC_SITE_URL` != production URL) shows a banner and blocks indexing.
